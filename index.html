Como funciona a inserção da imagem do barco com os assentos em cima? Para colocar os nomes/assentos flutuando exatamente em cima de uma foto real de um barco, usamos a técnica de Posicionamento Relativo e Absoluto: O container principal da imagem ganha position: relative;. A imagem do barco fica preenchendo esse container (width: 100%; height: auto; display: block;). Cada caixa de assento (seat-box) ganha position: absolute; e definimos coordenadas exatas em porcentagem (top: X%; left: Y%;) para ela. Exemplo prático no CSS: CSS .boat-photo-container { position: relative; width: 100%; max-width: 350px; margin: 0 auto; } .boat-photo-container img { width: 100%; border-radius: 12px; } .seat-absolute { position: absolute; width: 60px; /* Ajuste fino da posição de cada banco sobre a foto */ } Código Completo Atualizado e Corrigido Nesta versão, ajustei rigorosamente a distribuição exata dos pescadores com base nos bancos configurados, corrigi o comportamento das telas para que o botão verde e os conteúdos apareçam perfeitamente sem cortes, e estruturei o layout para receber a imagem do barco de forma limpa.
